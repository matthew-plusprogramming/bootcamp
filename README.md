## Veggie Rescue Bootcamp

Veggie Rescue practice project for developers.

### Overview

Bootcamp is a small full-stack project with a Node/Express API and a Next.js client.

### Tech Stack

- Client: Next.js + React
- Server: Node.js + Express
- Language: TypeScript

### Repo Structure

- `client-website/` — Next.js frontend
- `node-server/` — Express API

### Prerequisites

- Node.js and npm

### Setup

Install dependencies for each package:

```bash
cd node-server
npm install
```

```bash
cd client-website
npm install
```

### Development

Run the server and client in separate terminals:

```bash
cd node-server
npm run dev
```

```bash
cd client-website
npm run dev
```
