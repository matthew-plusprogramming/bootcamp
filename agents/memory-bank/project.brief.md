# Project Brief

Bootcamp repo for beginner developers to practice Git workflows and small
frontend/backend tasks. The repo includes a Next.js client app and an Express
API server.

Scope & High Level Goals

- Provide guided Git exercises (branching, merging, conflicts) using the repo.
- Provide small frontend tasks in `client-website` (fix a bug, create a
  component, and use it).
- Provide small backend tasks in `node-server` (fix a bug in an endpoint and add
  a simple endpoint that reuses existing services).
- Keep exercises small, isolated, and easy to reason about.

Out of Scope & Non Goals

- Production deployment, infrastructure, or cloud provisioning.
- Large refactors, framework migrations, or performance tuning.
- Full test coverage or CI hardening beyond what exercises require.

Primary Users & Stakeholders

- Beginner developers learning Git and full-stack basics.
- Instructors/maintainers who curate exercises.
- Agents assisting with small, scoped updates.

Project Stage
Bootcamp scaffolding with starter code and starter tests for practice tasks.

Success Criteria

- Memory Bank reflects the bootcamp scope, repo layout, and entrypoints.
- Learners can run `npm run dev` in `client-website` and `node-server`.
- Each exercise is solvable with small, localized changes.
- Git practice tasks (merge/conflict) are reproducible with the current repo.
