# Product Context

Intent & UX Goals

- Provide a friendly, low-friction learning environment for beginner devs.
- Keep tasks small and explicit with clear before/after outcomes.
- Encourage reading existing code before editing.

Primary Users

- Beginner developers in a bootcamp or self-guided practice.
- Instructors/mentors curating tasks and reviewing submissions.

Key UX Principles

- Clarity over cleverness; straightforward structure and naming.
- Minimal setup; run from repo root or per app directory.
- Safe to experiment; exercises should be recoverable with Git.
